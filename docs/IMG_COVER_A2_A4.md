## 3. 미공개 X1~X3 쓰는 법 (C9)

- 페이지에서는 **버튼을 눌러야 보이는 자리**에만 둔다: A2 관중석, A3 심사위원석(경기마다 표), A4 고객 대기열·고객 반응.
- 그림에서는 실루엣 + 흰 점 눈 + 소품 하나. 대사는 소리만 「(…)」「(반짝)」「(짝짝)」.
- 표지에는 넣지 않는다(본문에 늘어놓지 않는다는 규칙). 컷·아웃트로 배경에만.

## 4. 받은 뒤 넣는 법

1. `build_character_pack.py --ingest ./받은그림 --plates cover_A2=L,cut_A2_lv4=G,cut_A2_versus=G,sc_A2_outro=E --out received_A2` (A3·A4도 같음)
2. 표지: `src/A?/body.html`의 `<!-- lab-cover -->` 안을 `<img class="cv" src="assets/img/cover_A?.webp" width="1600" height="900" alt="…" fetchpriority="high">` 한 줄로 바꾼다(A1과 같은 꼴).
3. 컷·아웃트로: 위 표의 자리에 `<figure class="scene" data-img="키"><img src="assets/img/키.webp" … loading="lazy" alt="…"></figure>`.
4. `python3 src/shared/build_page.py A2` → og·thumb를 표지에서 다시 자르고 `cover_manifest.json`의 `status`를 `placeholder` → `ok`로.
5. 그림 합계: 페이지 HTML(370~435 KB, 캐릭터 그림 포함) + 그림 4장 ≈ 표지 220 + 컷 2×60 + 장면 120 KB 안팎.
