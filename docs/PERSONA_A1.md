# A1 RAG 연구실 — 페르소나 평가 (1차, 2026-11-20)

자기 결과물 평가이므로 빈 곳에 무게를 두었다. 5점 만점, 0.5 단위. 비교 대상 이전 점수 없음(첫 평가).

## 1. 페르소나

| # | 페르소나 | 이번에 보는 것 |
|---|---|---|
| A | 입문 독자 (AI를 처음 접하는 직장인) | 3줄 상자만 읽고도 무엇인지 아는가, 버튼만 눌러 따라오는가 |
| B | A의 상사 (팀장) | 업무에 RAG를 넣을지 판단할 근거가 있는가 |
| C | 숫자에 강한 실무자 | 수치가 재현되는가, 장난감 결과를 일반화하지 않는가 |
| D | 성인 학습자 (강의 수강생) | 퀴즈·학교 수학 연결이 기억에 남는가 |
| E | 원자료 저자 (ML Tut) | 원자료 내용이 왜곡 없이 옮겨졌는가, 바꾼 곳이 밝혀졌는가 |
| F | 분야 전문가 (NLP 연구자) | 방법론 정확성, 과장 없음 |
| +1 | 고등학생 | 학교 수학(집합·벡터·확률)으로 따라오는가 |
| +2 | 비전공 직장인 | 영어 예문이 장벽이 되는가 |

## 2. 점수

| # | 점수 | 한 줄 총평 |
|---|---|---|
| A | 4.0 | 사서 비유와 「책 없이/오픈북 시험」이 쉽다. ③단계 수식 상자는 여전히 가장 무겁다 |
| B | 3.5 | 「검색이 틀리면 답도 틀린다」와 현장 상자는 좋지만, 비용·보안·평가 방법은 다음 편으로 미뤘다 |
| C | 4.0 | 모든 수치가 같은 데이터에서 재계산되고 파이썬 검산과 일치. 숫자 8개짜리 벡터가 손으로 만든 값임을 밝힘 |
| D | 4.5 | 단계마다 학교 수학 단원과 계산 문항, 퀴즈 10문항 |
| E | 4.0 | 0.99→0.997, 흐름도 화살표, 낡은 코드를 「바꾼다」 표로 밝힘. 원자료 발행일·주소는 미확인 |
| F | 3.5 | 코사인·청크·top-k 설명은 정확. 실제 임베딩은 수백~수천 개이고 숫자마다 이름이 없다는 한계를 적었으나, 재순위(reranking)·하이브리드 검색 언급이 없다 |
| +1 | 4.0 | 집합·벡터·등차수열·확률의 곱으로 연결 |
| +2 | 3.5 | 「내 언어」 토글이 있지만 캔버스 속 카드 번호만 보고는 문장 내용을 알기 어렵다 |

입문 무리(A·D·+1·+2) 평균 4.0, 전문가 무리(C·E·F) 평균 3.8 — 차이 1점 미만(완료 기준 충족).

## 3. 상세

| 페르소나 | 좋았던 점 | 부족한 점 | 보완 제안 |
|---|---|---|---|
| A | 3줄 상자, 단계 대화, 사서 로봇 | ③단계 수식 상자 표가 길다 | ③단계 표를 「내적 → 길이 → 나누기」 세 단계 그림으로 |
| B | ⑤단계 확률 곱 0.855 | 도입 판단 기준 없음 | 「RAG가 맞는 일 / 안 맞는 일」 체크리스트 한 상자 |
| C | 대결 숫자가 계산값 | 데이터가 주제별로 깔끔해 큰 조각도 잘 됨 | 주제가 섞인 문서 예시를 ④단계 선택지로 추가 |
| E | 바꾼 곳 표 | 출처 링크 없음 | 원자료 주소를 받으면 바닥글·꾸러미에 채움 |
| F | 정확성 표현 절제 | 재순위·하이브리드·평가 지표 없음 | 정리 섹션에 「더 나아가면」 세 줄(재순위, 키워드+뜻 혼합, 평가) |
| +2 | 토글 | 서가 카드에 문장이 안 보임 | 카드를 누르면 문장(영/한)이 뜨는 말풍선 |

## 4. 종합 과제

| 순위 | 항목 | 대상 | 제기 | 난이도 | 기대 효과 |
|---|---|---|---|---|---|
| 1 | 원자료(ML Tut) 주소·발행일 채우기 | 바닥글·꾸러미 | E | 하 | 출처 확인 배지 완성 |
| 2 | 서가 카드 누르면 문장 보기 | ②~⑤ 실험 | +2, A | 중 | 영어 장벽 완화 |
| 3 | 「더 나아가면」 세 줄 (재순위·혼합 검색·평가) | 정리 | F | 하 | 전문가 신뢰 |
| 4 | 주제가 섞인 문서 선택지 | ④단계 | C | 중 | 조각 크기의 진짜 트레이드오프 |
| 5 | RAG 도입 체크리스트 | ⑤단계 현장 상자 | B | 하 | 업무 판단 |

반영 여부를 정해 주시면 같은 페르소나로 다시 평가합니다.
