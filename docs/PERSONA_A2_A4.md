# A2~A4 페르소나 평가 (1차, 2026-11-27)

자기 결과물 평가이므로 빈 곳에 무게를 두었다. 5점 만점, 0.5 단위. 근거는 페이지에 실제로 있는 문장·수치·실험만 썼다. 숫자는 `src/verify_numbers.js`(105개 항목 통과)로 다시 계산했다.

## 0. 대상 요약

- **A2 미세조정 연구실** — 퓨샷 예시 → 지도 미세조정(손실·무게 고치기) → 학습률·에포크·기록 실수 → LoRA. 숫자 32개짜리 장난감 분류기를 페이지 안에서 실제로 학습시킨다. 형식: **팀 대항전 3라운드**(프롬프트 팀 초파리·시아 vs 미세조정 팀 주판봇·모아, 2:1 미세조정 팀).
- **A3 평가 연구실** — EM·F1 → 블라인드 쌍대 비교와 엘로 → LLM 심판의 위치·길이 편향 → 신뢰구간. 형식: **개인전 리그 4인**(모아 1위, 초파리·주판봇 공동 2위, 시아 기준선). X1~X3가 블라인드 심사위원.
- **A4 에이전트 연구실** — 도구 호출 → ReAct 고리·걸음 예산 → 곱해지는 실수와 확인 → 프롬프트 주입과 세 겹 안전장치. 형식: **협동 레이드**(여섯 식구가 에이전트의 부품, 한 명씩 빼 보기). X1~X3가 고객.
- 세 편 모두 박사의 상황 질문·해석 문장, 조수의 수식 상자, AI 판단 코너, 30초 복습, 확인 퀴즈 8문항, 지식 색인·꾸러미, 「사이트 안에서 더 읽기」(성장 지도 연결) 포함.

## 5. 정리

입문·학습자 쪽(A, D, +1)은 비유와 리듬, 퀴즈를 높게 봤고, A3의 영어 답변과 통계식에서 점수가 깎였다. 실무·전문가 쪽(C, F)은 수치 재현성은 인정했지만, 손으로 정한 모형 값(A2 퓨샷 모형, A4 레이드 매개변수)이 본문 결론을 떠받친다는 점을 지적했다. 팀장(B)과 교수자(E)는 대결 형식과 정리 표를 가장 쓸모 있게 봤다. 먼저 고칠 것은 ① 실험 패널 안의 모형 가정 문구(하), ② A3 답변 언어 기본값(하), ③ A4 레이드 민감도 표(중) 세 가지다. ①·②는 평가 직후 바로 반영했다.
